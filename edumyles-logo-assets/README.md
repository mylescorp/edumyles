# EduMyles logo assets (Tidepool recolour)

Derived from the two supplied PNGs: backgrounds removed, navy and blue recoloured to the Tidepool teal family, gold and green kept. These are raster derivatives, not true vectors.

| File | Use |
|---|---|
| edumyles-lockup-light / -dark.png | Login page, marketing, email header (includes tagline). Minimum width 320px |
| edumyles-wordmark-light / -dark.png | App header (32 to 40px tall), emails, invoices. No tagline |
| edumyles-mark-light / -dark.png | Collapsed sidebar (72px), avatars, app icon |
| edumyles-wordmark-ink / -white.png, edumyles-mark-ink / -white.png | One colour: greyscale print, PDFs on tinted paper, watermarks |
| favicon.ico, favicon-32 / 64 / 192 / 512.png | Browser tab, PWA, home screen |

Rules
- Light files go on light surfaces (surface-default, surface-raised in light mode). Dark files go on dark surfaces. Never place a light file on a dark surface.
- Clear space on every side: 25% of the mark height. Minimum wordmark height 24px, minimum mark height 16px.
- The gold in the wordmark is a logo colour only. It is 1.8:1 on white: never use it for UI text.
- Tagline wording: "Empowering schools, one mile at a time" is how it appears in the artwork ("One mile at a Time"). Choose one form and fix it at the source before the redraw.
- Platform panels (/platform) and the login page use these files. A tenant's own logo replaces them inside the tenant workspace; "Powered by EduMyles" uses the mark only.

Known limits: raster resolution tops out at about 1200px wide. Request a redrawn SVG (sanitized) for large print, signage and merchandise. Wordmark and mark crops were cut automatically; check edges at 400% zoom before print use.
