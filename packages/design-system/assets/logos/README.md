# EduMyles logo assets v2 (platform palette)

Recoloured from the previous Tidepool set to the EduMyles platform tokens. Artwork, proportions and tagline are unchanged. Raster derivatives, not vectors.

| Colour in logo | Value | Token |
|---|---|---|
| Navy (cap, "Edu", people, tagline) | #1A395B | platform chrome / navy 700 |
| Blue (side figures, accents) | #1565C0 | primary (light) |
| Gold ("Myles", star, page stripe) | #C79639 | gold 500 |
| Green (lower page stripe) | #008B50 | kept from the original artwork |
| Dark-surface blue | #6FA2F3 | primary (dark) |
| Dark-surface white | #F8FAFC | foreground (dark) |

Files: lockup (with tagline), wordmark, mark, in light / dark; ink (#171717) and white (#F8FAFC) one-colour versions; favicons 32/64/192/512 + .ico.
Rules: light files on light surfaces (#FFFFFF, #F4F4F5), dark files on dark surfaces (#0B111C, #172235). Clear space 25% of mark height. Minimum wordmark height 24 px, mark 16 px. Gold is a logo colour only: 2.7:1 on white, never for UI text.
